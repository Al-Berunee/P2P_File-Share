⚡ Peer-to-Peer File Share

Direct browser-to-browser transfer. Files never touch a server — only this page and manual copy-paste of connection codes.

1Pick your files

Multiple files allowed. They will be sent one after another.

2Create a connection code

Send this code to the receiver (WhatsApp, Messenger, anything).

3Paste the receiver's reply code

The receiver generates this after pasting your code in step 2.
